Design Recommendations

1. Visual Override Indicator Recommended

Show amber/yellow badge directly in the table row when any manual override is active. Makes it immediately visible which positions have overrides without opening the detail panel.

2. Two Override Modes

Override Price: Direct price input - simple, quick, overrides everything.

Override Model Inputs: Change specific inputs (vol, rates) - model recalculates price. More granular control, audit trail shows what was changed.

3. What-if Preview Recommended

Show real-time preview of impact before applying. User sees new price, new P&L, new market value instantly as they type. Reduces errors and gives confidence.

4. Reset to Default

Prominent "Reset" button in warning banner. Clearly states what default is (Market price or Model with default inputs). One-click to remove all overrides.

5. Audit Trail

Track who made overrides and when. Essential for compliance. Show last N overrides in the panel, full history available via link.

6. Pricing Source Badge

Clear indicator of current pricing source:
Market - observed price
Model - calculated price
Manual - user override

! Key UX Decision: When a user overrides a model input (like volatility), the price badge should show "Model + Override" (purple with amber accent) to indicate it's still model-priced but with modified inputs. This is different from a direct price override where the badge shows "Manual" (amber).
