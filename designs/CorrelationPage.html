Implied Correlation Methodology
Corr(A,B)_implied = Σ [ β_A,i × β_B,i × √(w_A,i × w_B,i) ] Where: β_A,i = Portfolio A's correlation to anchor i β_B,i = Portfolio B's correlation to anchor i w_A,i = Portfolio A's allocation to RiskPod i w_B,i = Portfolio B's allocation to RiskPod i Total Implied Correlation = Σ (RiskPod_Corr × Avg_Weight) = 0.78×0.35 + 0.65×0.225 + 0.52×0.275 + 0.15×0.075 + (-0.12)×0.04 + 0.08×0.035 = 0.273 + 0.146 + 0.143 + 0.011 - 0.005 + 0.003 = 0.42
How it works:
  • Anchor Correlation measures how each portfolio moves with market benchmarks (SPX for Equity, US10Y for Rates, etc.)
  • RiskPod Weight is the average allocation of both portfolios to each asset class
  • Portfolios with similar anchor correlations AND similar weights will have high implied correlation
  • Compare Implied (model-based) vs Realized (historical P&L) correlation to detect hidden risks
